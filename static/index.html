🔑 Free API keys (optional — more live data)
Get free keys at twelvedata.com, finnhub.io or alphavantage.co. They add real-time/live US & global quotes. Your dashboard already works without them.
📱 Telegram bot (free phone alerts + chat with advisor)
Free setup: open Telegram → search @BotFather → /newbot → copy the token. Then send any message to your new bot and click Auto-find my chat id. You can then chat with your advisor from Telegram (try /help).
⚡ Zerodha Kite (true NSE live + your real holdings)
Free Zerodha account → developers.kite.trade → create app → get API key & secret → generate an access token (needs `pip install kiteconnect`). This enables true NSE live prices and your actual holdings.
🇮🇳 Angel One SmartAPI (free real-time NSE for Angel One customers)
Free with an Angel One account: register at smartapi.angelbroking.com, create an app to get the API key, and use your normal login + authenticator TOTP. Needs pip install smartapi-python. Gives true NSE real-time prices + candles.
🔎 Google Finance fallback (free, no key)
Google Finance has no official API, so this parses the public quote page as a safety net when Yahoo Finance is slow or blocked. No key needed.
For Gmail: enable 2-Step Verification, then create an App Password (Google Account → Security → App passwords). Credentials are stored only in your workspace (data/settings.json).
